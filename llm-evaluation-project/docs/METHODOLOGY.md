# Evaluation Methodology and Mathematical Formulation

This document details the scientific methodology, mathematical definitions, evaluation protocols, and experimental procedures implemented in the Enhanced LLM Evaluation Framework.

---

## 1. Research Question and Hypotheses

### Primary Research Question
> *"Can a multi-metric LLM evaluation framework, combining G-Eval with traditional metrics and human-alignment analysis, provide more reliable model rankings than any single automatic evaluation metric?"*

### Hypotheses
- **$H_1$ (Metric Complementarity)**: G-Eval excels at semantic and high-level quality dimensions (coherence, consistency) but may suffer from hallucination or verbosity bias. Traditional surface metrics (ROUGE, BLEU) and embedding metrics (BERTScore) offer orthogonal lexical and token-level constraints.
- **$H_2$ (Composite Superiority)**: A unified score combining G-Eval, BERTScore, ROUGE, and an unsupervised ensemble agreement term will achieve higher summary-level and system-level rank correlation with expert human ground truth than any individual metric alone.
- **$H_3$ (Bias Mitigation)**: Multi-model ensembling attenuates evaluator-specific biases (e.g., system type preferences, length bias, and self-preference).

---

## 2. Dataset: SummEval Benchmark

The framework benchmarks against the standard **SummEval** dataset (*Fabbri et al., TACL 2021*):
- **Structure**: 100 source news articles from CNN/DailyMail.
- **Systems**: 16 summarization systems (extractive algorithms: *M0–M5*; neural abstractive architectures: *M8–M23*).
- **Total Records**: $100 \times 16 = 1,600$ summary evaluations.
- **Human Ground Truth**: Each summary is independently annotated by 3 expert annotators and 5 crowd-workers across 4 criteria:
  - **Coherence** (1–5): Well-structured, logical organization and flow.
  - **Consistency** (1–5): Factual alignment with the source; penalty for hallucinations.
  - **Fluency** (1–3): Grammatical correctness, punctuation, and linguistic naturalness.
  - **Relevance** (1–5): Selection of salient information; penalty for redundant or extraneous details.
  - **Overall** (1–5): Arithmetic mean of the 4 dimension scores.

## 3. G-Eval Formulation

### 3.1 Prompt Architecture
Each evaluation prompt comprises six components:
1. **Task Introduction**: Defines the evaluation role and objective.
2. **Evaluation Criteria**: Formal definition of the specific metric (Coherence, Consistency, Fluency, or Relevance).
3. **Evaluation Steps (Auto-CoT)**: Step-by-step instructions generated once by an LLM and cached.
4. **Input Context**: The complete source article text (`{{Document}}`).
5. **Input Target**: The candidate summary generated by a system (`{{Summary}}`).
6. **Evaluation Form**: Explicit constraint to output only the numerical score.

### 3.2 Continuous Expectation via Probability Weighting
To eliminate discrete quantization noise and capture evaluation uncertainty, G-Eval computes a continuous expected score.
Let $\mathcal{S}$ denote the set of valid score tokens (e.g., $\{1, 2, 3, 4, 5\}$ for Coherence or $\{1, 2, 3\}$ for Fluency). Let $p(s)$ denote the model's conditional probability for token $s$.
The normalized probability $w_s$ is:
$$w_s = \frac{\exp(\log p(s))}{\sum_{s' \in \mathcal{S}} \exp(\log p(s'))}$$
The continuous G-Eval score $S_{\text{G-Eval}}$ is the mathematical expectation:
$$S_{\text{G-Eval}} = \sum_{s \in \mathcal{S}} s \cdot w_s$$

### 3.3 Sampling Fallback Mode
When logprobs are unavailable, the framework falls back to $n=20$ stochastic samples ($T=1.0$):
$$S_{\text{G-Eval}} = \frac{1}{n} \sum_{i=1}^{n} s_i$$
where $s_i$ is the parsed numerical score from sample $i$.

### 3.4 Ablation Studies
Four ablation modes are implemented to quantify the contribution of each component:
- `full`: Complete G-Eval (Auto-CoT steps + probability-weighted expectation).
- `no_probs`: Auto-CoT steps present, but evaluated greedily ($T=0.0$, argmax score).
- `no_cot`: Probability-weighted expectation, but evaluation steps removed.
- `no_description`: Bare prompt containing only the dimension name without definitions or steps.

## 4. Traditional Metrics

To establish comprehensive baselines, the framework computes 12 traditional metric variants:

1. **ROUGE (F1 Scores)**:
   - Reference-based: `rouge1_ref`, `rouge2_ref`, `rougeL_ref`
   - Reference-free (vs. source document): `rouge1_src`, `rouge2_src`, `rougeL_src`
2. **BLEU**:
   - Sentence-level SacreBLEU normalized to $[0, 1]$: `bleu_ref`
3. **BERTScore**:
   - Computes Precision, Recall, and F1 based on token embedding cosine similarity using `roberta-large` (or `distilbert-base-uncased` CPU fallback):
     - Reference-based: `bertscore_P_ref`, `bertscore_R_ref`, `bertscore_F1_ref`
     - Reference-free (vs. source document): `bertscore_P_src`, `bertscore_R_src`, `bertscore_F1_src`

## 5. Correlation Protocols

Metrics are evaluated against human ground truth at three distinct levels:

### 5.1 Summary-Level Correlation (Paper Standard)
For each source document $d \in \{1, \dots, 100\}$, candidate summaries from all 16 systems are ranked by metric score and human score. Spearman's $\rho_d$, Kendall's $\tau_d$, and Pearson's $r_d$ are calculated:
$$\bar{\rho}_{\text{summary}} = \frac{1}{100} \sum_{d=1}^{100} \rho_d$$
This isolates intra-document ranking ability from inter-document difficulty variance.

### 5.2 System-Level Correlation
Scores for each system $m \in \{1, \dots, 16\}$ are averaged across all 100 documents:
$$\bar{S}_m = \frac{1}{100} \sum_{d=1}^{100} S_{m, d}, \quad \bar{H}_m = \frac{1}{100} \sum_{d=1}^{100} H_{m, d}$$
Rank correlation is computed over the 16 $( \bar{S}_m, \bar{H}_m )$ pairs to measure accuracy in selecting the best model overall.

### 5.3 Pooled Sample-Level Correlation
Direct correlation across all 1,600 summary pairs without grouping.

### 5.4 Statistical Significance & Bootstrap Confidence Intervals
95% Confidence Intervals are generated using 1,000 cluster bootstrap resamples grouped by `doc_id`. Grouping by document preserves intra-document correlation structure during resampling.

## 6. Evaluator Bias Analysis (Experiment F)

The framework systematically tests for five known failure modes of LLM judges:

1. **Per-System Bias**:
   Measures system-specific residuals:
   $$\text{Bias}(m) = \frac{1}{N_m} \sum_{i \in m} \left( z(S_i) - z(H_i) \right)$$
   Tested for statistical significance using two-sided paired $t$-tests ($p < 0.05$).
2. **Length Bias**:
   Spearman and Pearson correlation between metric score and summary token/word count:
   $$\rho_{\text{length}} = \text{Corr}(S, \text{Length})$$
3. **Extractive Style Bias**:
   Measures extractive coverage (percentage of summary tokens in shared source n-grams) and extractive density vs. residual prediction error $(S - H)$.
4. **System Type Bias**:
   Compares mean residuals between extractive systems (*M0–M5*) and neural abstractive models (*M8–M23*).
5. **Residual Distribution Analysis**:
   Visualized via residual scatter plots and Q-Q plots saved to `results/figures/`.

## 7. Unified Evaluation Score Formulation (Experiment G)

All candidate component metrics are normalized to $[0, 1]$ using min-max scaling:
$$x' = \frac{x - \min(x)}{\max(x) - \min(x)}$$

### 7.1 Fixed-Weight Combination
$$\text{Unified}_{\text{fixed}} = 0.40 \cdot \text{G-Eval}_{\text{overall}} + 0.25 \cdot \text{BERTScore}_{\text{F1}} + 0.15 \cdot \text{ROUGE-1} + 0.20 \cdot \text{EnsembleAgreement}$$
where $\text{EnsembleAgreement} = \text{Normalize}(1.0 - \sigma_{\text{judges}})$.

### 7.2 Simplex Grid Search
Searches weight space $(w_1, w_2, w_3, w_4)$ subject to $w_i \ge 0, \sum w_i = 1.0$ at step size $\Delta = 0.05$ to maximize summary-level Spearman correlation.

### 7.3 Learned Combiner (Ridge Regression)
Trains a regularized linear model:
$$\min_{\mathbf{w}} \frac{1}{2} \| \mathbf{y} - \mathbf{X} \mathbf{w} \|_2^2 + \alpha \| \mathbf{w} \|_2^2$$
Evaluated with 5-fold `GroupKFold` grouped by `doc_id` to strictly prevent source document leakage across folds. Out-of-fold (OOF) predictions are used to compute unbiased validation correlations.

## 8. Human Validation and Inter-Rater Reliability (Experiment D)

- **Subset Sampling**: Selects a balanced subset of 160 summaries stratified across all 16 systems and across 3 human score tertiles (low, medium, high).
- **Template Generation**: Exports `dashboard/human_rating_template.csv` for blind human re-annotation.
- **Inter-Rater Reliability (IRR)**:
  When multiple annotator columns are present in `data/human_ratings.csv`, the framework computes:
  - Pairwise Spearman $\rho$ across annotators.
  - Krippendorff's $\alpha$ for ordinal/interval scale data.
